# PDF Manager Telegram Bot 🤖📄

یک ربات تلگرامی قدرتمند و پیشرفته بر پایه **Telethon** و **PyMuPDF** برای مدیریت حرفه‌ای فایل‌های PDF شامل تنظیم تامبنیل (کاور)، درج واترمارک هوشمند و حذف اصولی تبلیغات.

---

## 🌟 قابلیت‌ها

### ۱. تنظیم تامبنیل اختصاصی (Thumbnail)
- **حالت خودکار (Auto):** استخراج خودکار صفحه اول PDF با کیفیت بالا و قرار دادن آن به عنوان پیش‌نمایش در تلگرام (حل مشکل عدم نمایش کاور در اندروید و دسکتاپ).
- **حالت سفارشی (Custom):** امکان ارسال عکس دلخواه برای استفاده به عنوان کاور تمام فایل‌های ارسالی.
- **پردازش تکی و دسته‌ای (Batch):** امکان انتخاب و ارسال چندین فایل PDF به صورت همزمان.

### ۲. درج واترمارک و لوگو هوشمند (Watermark Inserter)
- **عدم تداخل با متن:** آنالیز دقیق Bounding Boxes تمام متون صفحه و قرار دادن لوگو منحصراً در حاشیه‌ها و گوشه‌های خالی.
- **موقعیت‌های متنوع:** گوشه پایین-راست، پایین-چپ، بالا-راست، بالا-چپ، و **🎲 گوشه تصادفی (رندوم)**.
- **انتخاب صفحات:** اعمال روی تمام صفحات، فقط صفحه اول، یا صفحات تصادفی.

### ۳. حذف اصولی و تمیز واترمارک قبلی (Watermark Remover)
- **شناسایی لایه‌ای:** تشخیص هوشمند تصاویر تکراری (لوگوها و واترمارک‌های کانال‌ها) و حذف مستقیم از ساختار باینری فایل بدون هیچ‌گونه افت کیفیت، تاری یا آسیب به متن.
- **حذف آیدی و لینک:** امکان وارد کردن آیدی تلگرام یا لینک سایت جهت پاکسازی دقیق از کل صفحات.

### ۴. رابط کاربری ساده و کارآمد
- تعامل کامل از طریق **دکمه‌های شیشه‌ای (Inline Buttons)**.
- دکمه‌های سریع در پنل پایین (**Reply Markup**) جهت سوئیچ سریع تنظیمات.

## 🚀 نصب و راه‌اندازی

### ۱. کلون کردن ریپازیتوری
```bash
git clone https://github.com/PouriaPH1/pdf_mng-bot.git
cd pdf_mng-bot
```

### ۲. نصب پیش‌نیازها
```bash
pip install -r requirements.txt
```

### ۳. تنظیمات
فایل `config.py` را باز کرده و اطلاعات تلگرام خود را وارد کنید:
```python
API_ID = 12345678              # از my.telegram.org
API_HASH = "YOUR_API_HASH"     # از my.telegram.org
BOT_TOKEN = "YOUR_BOT_TOKEN"   # از @BotFather
```

### ۴. اجرای ربات
```bash
python bot.py
```
